# Second Brain — Indice

Punto di partenza. Da leggere sempre a inizio conversazione. Ogni file qui dentro è collegato agli altri tramite link relativi `[testo](file.md)`.

## Mappa dei file

- [progetto.md](progetto.md) — cos'è questo progetto, obiettivi, stack
- [decisioni.md](decisioni.md) — decisioni prese e perché (architettura, scelte tecniche)
- [preferenze.md](preferenze.md) — come l'utente vuole lavorare con me
- [log.md](log.md) — cronologia sintetica delle sessioni di lavoro

## Come funziona questo sistema

1. **A inizio chat**: rileggo questo indice e i file collegati rilevanti per il task.
2. **Durante la chat**: se emergono fatti nuovi, decisioni, preferenze o problemi rilevanti per il futuro, li annoto.
3. **A fine chat**: aggiorno i file pertinenti (nuove sezioni o modifiche a quelle esistenti, non solo append) e aggiorno [log.md](log.md) con una riga di sintesi.

## Regole di scrittura

- File brevi, uno per argomento. Se un file cresce troppo, lo spezzo e linko.
- Ogni fatto ha una data (formato YYYY-MM-DD) quando è temporale/decisionale.
- Non duplico qui informazioni derivabili dal codice o da git log.
- Link liberi tra i file, anche verso file non ancora creati (marcano cosa manca).
